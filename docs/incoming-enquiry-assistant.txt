SERVER SETTINGS

VOICE_ENQUIRY_TWILIO_NUMBER=the Twilio voice ingress in +44 format.
VOICE_ENQUIRY_TEST_CALLERS=comma-separated approved test callers in +44 format.
VOICE_ENQUIRY_PROJECT_ID=the OpenAI project starting proj_.
VOICE_ENQUIRY_BRIDGE_SECRET=random secret at least 32 characters.

ENDPOINTS
POST /api/voice-enquiries/twilio/incoming — signed Twilio form webhook.
POST /api/voice-enquiries/twilio/finished — signed Twilio continuation/fallback.
POST /api/voice-enquiries/openai/webhook — signed raw JSON OpenAI webhook.
Mount before the application-wide JSON parser. No unsigned public write endpoint is exposed.

TEST LIMITS AND LIMITATIONS
One active test call and five accepted test calls per UTC day per process; these are IN-MEMORY test limits and reset on restart. They are NOT a durable financial cap or ready for multiple backend replicas. The carrier Dial leg has a six-minute time limit as well as a server timer, so it does not rely solely on the backend remaining alive. Caller allowlisting is a test restriction, not identity verification for private records; none are exposed.
A production rollout needs persistent usage/cost controls, monitoring, durable call-state/recovery, approved human escalation, and a live acceptance test. The prototype does not promise recovery of details if a caller disconnects before confirming an enquiry. No raw call recording or full transcript storage is added by this code; provider processing and retention still depend on account configuration.

ACCEPTANCE TESTS BEFORE MOBILE FORWARDING
Normal new wedding enquiry; incomplete/undecided date; caller declines AI; human callback; wrong email/phone correction; silence/interruption; existing booking problem; caller requests unverified availability or price; tool/storage failure; duplicate tool delivery; forged webhook; unapproved caller; disconnect; six-minute cutoff and provider fallback.

ROLLBACK
Leave VOICE_ENQUIRY_ENABLED=false and keep the mobile provider's existing routing. Once testing has begun, remove the dedicated test number's new voice handler or restore its saved previous voice settings. Do not change WhatsApp/SMS webhooks or the emergency IVR.
